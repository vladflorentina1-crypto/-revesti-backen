# ReVesti Backend – Starter

Node.js + Express + SQLite starter for the ReVesti marketplace.

## Start
1. Install Node.js 20+.
2. Run `npm install`.
3. Set a strong `JWT_SECRET` environment variable.
4. Run `npm start`.
5. Open http://localhost:3000

This is a development starter, not production-ready. Before launch: HTTPS, secret management, production database, rate limiting, email verification, password reset, audit logs, payment provider/marketplace KYC, secure image storage, backups, monitoring and legal documents are required.
